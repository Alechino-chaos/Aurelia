# Aurelia 0.4.2 轻量安全检查

日期：2026-10-12。范围：当前源码、锁定依赖、Windows Electron 程序、API 配置与请求、Markdown/PDF 显示、会话保存。使用隔离测试目录、测试 Key 和本机模拟 API，没有读取个人 API Key 或向真实 AI 服务发送论文。

## 发现与修复

| 项目 | 判断 | 处理 |
| --- | --- | --- |
| Electron 40.10.6 安全公告 | 高优先级依赖告警；npm 将它列在开发依赖中，但实际随桌面程序分发，不能只扫描生产依赖 | 升级到 44.7.0；校验官方运行文件 SHA-256，并在桌面测试中核对实际运行版本 |
| 构建代理依赖 | `sprintf-js` 的中危拒绝服务公告沿 `roarr → global-agent → @electron/get` 传播，共计 8 个依赖节点告警，不是 8 个独立漏洞 | 固定 `global-agent` 到 4.1.3，移除有问题的日志依赖链，验证原有 bootstrap API 与打包流程 |
| 多进程写入同一配置目录 | 缺少进程间协调，重复启动可能覆盖另一窗口保存的会话 | 增加每个配置目录的单实例锁，重复启动唤起已有窗口，第二进程不加载或写入记录 |
| IPC 来源校验 | 旧判断在开发地址与来源 URL 均缺失时存在放行条件，且未明确要求主框架；未证实可从普通 PDF/聊天内容触发 | 要求非空可信 URL、当前窗口及主框架同时匹配 |
| 页面权限 | 原策略未明确禁用子框架/表单，生产包保留开发 WebSocket 地址 | 增加 `frame-src 'none'`、`form-action 'none'`，WebSocket 放行仅限 Vite 开发模式 |
| 依赖锁文件 | 部分条目的版本与可下载文件不一致，升级安装返回 404 | 备份后按实际可用依赖重新生成锁文件；应用版本只对应根包，不修改第三方包版本 |

Electron 公告涉及特定配置。Aurelia 已禁止弹窗、webview，且没有注册自定义文件/HTTP 协议处理器；这些现有限制阻断了部分公告的触发条件。本次没有发现利用成功的证据，也没有把依赖告警直接等同于应用已被攻破。参考：[弹窗沙箱继承公告](https://github.com/electron/electron/security/advisories/GHSA-gr2m-v5gq-v685)、[协议跨源读取公告](https://github.com/electron/electron/security/advisories/GHSA-j84w-jfhq-vhvj)。

锁文件重新解析还更新了兼容范围内的 React 19.3.0、PDF.js 6.4.299，因此验证覆盖完整阅读流程，不仅是新增的权限检查。

## 已检查的现有保护

- API Key 在主进程使用系统加密保存，设置读取接口不返回明文；系统安全存储不可用时拒绝明文保存。实际测试检查了测试 Key 落盘、重启恢复和读取接口。
- 远程 AI 地址要求 HTTPS；用户名、密码、查询参数和片段不允许放入 API 地址。更换服务商来源需重新提供 Key 或清除旧 Key。
- 请求禁止自动跟随重定向；实际 302 测试确认目标地址未被访问。服务商错误正文不会直接显示，测试 Key 未出现在错误事件中。
- 渲染进程启用 sandbox、contextIsolation，关闭 nodeIntegration；新窗口禁止弹出，其他窗口不能调用主窗口的特权接口。
- AI Markdown 不执行原始 HTML，不加载远程图片或自动打开链接；KaTeX 关闭信任模式、限制宏展开。
- 会话标识限定为 SHA-256 十六进制字符串，避免拼接任意文件路径；记录结构与体积受校验，采用临时文件替换及备份，保存失败会提示。

## 边界

这是轻量代码检查、已知依赖扫描和自动化回归，不是完整渗透测试，也不能证明没有未知漏洞。没有进行恶意 PDF 模糊测试、操作系统级攻击或 AI 服务商端审计。

聊天、翻译和批注是本机 JSON 记录，没有加密；API Key 的系统加密不等于这些内容也已加密。同一 Windows 账户下有权限的软件仍可能读取本地资料。

没有更换真实服务商设置、清除个人记录或关闭正在使用的旧窗口。升级使用时，请先正常关闭旧版本，再双击当前快捷方式。

## 验证

最终依赖扫描：`npm audit --json`，0 条已知告警（含 Electron 与构建依赖）。38 项单元测试通过；0.4.2 实际安装版完整 33 项 Electron 测试通过，用时 35.1 秒，包括 3 项新增安全测试。安装文件与打包输出的 app.asar 哈希一致，快捷方式已更新。

验证中修正了测试设置：同名论文切换需等待目标正文出现；外部测试窗口显式指定预加载路径；鼠标坐标测试固定显示缩放为 1，缩放清晰度测试独立使用 2 倍像素密度。最终 2 倍密度下，分块渲染与整页渲染的对比像素差异为 0。
