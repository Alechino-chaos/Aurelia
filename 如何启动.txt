Aurelia 启动说明

直接双击 Windows 桌面上的「Aurelia」快捷方式。
不需要打开终端，不需要输入命令。

打开软件后：
1. 点击「打开 PDF」，或者把论文 PDF 拖进窗口。
2. 也可以点击「体验双栏示例」试用。
3. 选中文字后，用 Ctrl+C 复制清理文本，Ctrl+Shift+C 原样复制。
4. 点击右上角齿轮，填写 API 地址、API Key 和模型名称，保存并测试。
5. 选中文字后点击「翻译」，或点击「问 AI」引用到右侧对话。
6. 对话中 Enter 发送，Shift+Enter 换行；可随时停止回答。
7. 右侧「复制选项」可切换文本顺序、原样复制、带出处复制与断词设置。
8. 选中文字后点击「高亮」或「批注」，在右侧「批注」中添加笔记、修改颜色和定位原文。
9. 批注会自动保存；删除后可以撤销。批注中「问 AI」的回答可追加保存到当前笔记。

AI 支持 OpenAI 兼容接口，API Key 在本机加密保存。
只有主动翻译或发送消息时才提交相关文字，原 PDF 不上传。
对话、翻译历史和未发送的草稿按论文自动保存到本机。
重新打开同一篇论文会自动恢复，切换论文时显示对应的记录。
新建对话会保留旧对话，可从右侧「对话记录」切换；译文可从「翻译记录」切换。
旧版本尚未保存的内容无法补录，首次升级前如需保留，请先复制。

软件关闭后，下次继续双击快捷方式即可。
请勿删除桌面快捷方式指向的 Aurelia 安装目录；实际路径记录在 .aurelia-install.local.json。

如需复制到另一台 Windows x64 电脑，可使用 release 文件夹里的
Aurelia-0.4.2-portable.exe，无需安装 Node.js。

开发者注意：修改源码不会自动更新这个独立程序，需要重新打包并更新快捷方式。
